# Foodie vs Foodpanda

An interactive, single-page strategy brief on why Foodie loses to Foodpanda on price, and what to do about it.

**Live site: https://himelpaul.github.io/foodie-vs-foodpanda/**

## What's inside

1. **Diagnosis** – delivery economics and why Foodpanda is cheaper on almost every basket.
2. **The fix** – a zone-first loop built around a membership, with metrics to track.
3. **Prototype** – a before/after app mock-up with a Foodie Plus toggle.

## Run locally

It's one static file. Open `index.html` in a browser.
